published legacy product with the unreleased Trialmark evidence layer.

## Maintainer state

- [`SESSION_HANDOFF.md`](SESSION_HANDOFF.md) and root
  [`AGENT_STATE.md`](../AGENT_STATE.md) record the current local development
  boundary and verification evidence.
- Unpublished audits, detailed active planning, and run artifacts live under
  the gitignored local `archive/` tree. They are intentionally absent from a
  fresh clone and from the public documentation site.

## Canonical sources

Edit files in `docs/`, `README.md`, or `CHANGELOG.md`. Files under
`docs-site/src/content/docs/guides/` are generated by
`docs-site/scripts/sync-docs.mjs` during `npm run build`; do not edit those
copies directly. `docs/API.md` is generated by
`python scripts/generate_api_docs.py`.
